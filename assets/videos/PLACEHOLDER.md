# Folder Video

Letakkan file video kamu di sini, contoh: hero-loop.mp4

Untuk mengganti background hero dengan video (bukan foto):
1. Taruh file video (.mp4, terkompresi) di folder ini.
2. Buka index.html, cari komentar <!-- HERO BACKGROUND -->
3. Ganti tag <img> dengan tag <video> sesuai contoh komentar di HTML.
