# Folder Icons / Logo

Taruh file logo asli kamu di sini (misalnya logo.png atau logo.svg).
Saat ini website menggunakan text logo "BALAI.SEMUT" (wordmark), bukan file gambar.

Cara mengganti dengan logo gambar:
1. Taruh file logo di folder ini, contoh: logo.svg
2. Buka setiap file HTML, cari class "nav-logo"
3. Ganti teks dengan <img src="assets/icons/logo.svg" alt="Balai.semut Logo">
